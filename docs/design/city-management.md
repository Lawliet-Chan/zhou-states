# 城市管理

城市管理是玩家花时间最多的玩法。玩家最多只能直接管理一座城市，其余城市需要交给士人、下属或门客管理。
城市管理的核心是：**通过士人，把城内的人口安排到具体的工事上去。**

## 士人的身份

技能槽中有「士」的人口，只表示他们具备士的能力，并不代表他们就是士人。只有被管理者任用的人才是士人。

- 技能槽中必须有「士」才能被任用为士人
- 只有士人才能被派去主事
- 所有士人都由府库供养，每回合的开支由府库承担。士人越多，府库负担越重
- 技能槽中有「士」但没有被任用的人口，和其他人口一样，可以被安排到工事中，或者在未被管理时自主民营

## 派士主事

玩家（管理者）不能直接操控人口，所有对人口的安排都必须派一名士人主事。

- 一名士人同一时间只能主事一项工事
- 一名士人能管理的人口有上限（见「士人管理上限」）
- 士人的能力影响工事的效率和质量
- 工事持续多个回合时，主事的士人在这期间一直被占用
- 工事中的人因为饿死、外流、丢弃了需要的技能等原因全部离开时，工事就此结束，主事的士人空出来；营建、开垦这类工事已经投入的进度和材料不退回

士人的数量决定了一座城能同时开展多少项工事，士人的能力决定了这些工事做得好不好。

## 工事

城内每一项具体的活动都是一项工事。一项工事由以下部分组成：

- 主事的士人：一名
- 投入的人口：从城内人群中抽调，人数不能超过主事士人的管理上限；人群的技能槽里必须有对应行业
- 原料：从府库或民间获得
- 设施：部分工事需要对应建筑，比如冶铸需要冶厂。官营的工事要用官营的建筑，民营的要用民营的
- 经营方式：官营或民营。在建筑里做的工事，经营方式跟着建筑走；种地、捕鱼这类不靠建筑的，由管理者选
- 产出：由投入人数、专精度、愉悦度、主事士人的能力决定

同一群人可以被拆分，分别投入不同的工事。

## 地块与劳作容量

城市由若干地块组成，比如耕地、水泽、山林、盐池、铜矿。地块之间没有主次之分：每块地都能住人、劳作、建建筑，区别只在能做哪一行。每块地有两个上限：

- 居住：每块地能住多少人，目前每种地都是 50 人。全城的居住上限 = 所有地块的居住人数 + 建筑增加的居住人数
- 劳作：每块地能容纳多少人劳作。比如一块耕地只能容纳 60 人种五谷，人再多也没有地可种

规则：
- 人口增长不会超过居住上限。各群人按各自想增长的多少，分配剩余的空间
- 人口因为其他原因超出居住上限时，全城拥挤，所有人群的愉悦度下降
- 靠地块劳作的行业（种五谷、捕鱼、制盐、狩猎、驯马、冶青铜、琢玉），劳作人数受这种地块的容量总和限制
- 不靠地块的行业中，经商的人数受市的限制（见「市与商贾」）。官营的市只容纳官营的商贾，民营的市只容纳民营的商贾；其余行业（纺织、铸兵器、制甲、铸礼器）暂不限人数
- 工事优先占用劳作位置：派士主事时，投入的人数不能超过剩余的位置，但不用和未被管理的人口争；未被管理的人口只能用剩下的位置，没有位置的人这一回合无事可做
- 改良过的地块产量更高，劳作时先占用产量高的地块

城市的地块数受所有者爵位的限制，超出视为僭越（见 city.md）。

## 开垦

城市要扩大，只能派士主事，带人开垦新的地块。

- 只能开垦城市旁边的一格，地形由地图决定。地图做出来之前，暂时由管理者指定开垦哪种地
- 各种地块基本都能开垦，但必须由会对应技能的人去开垦：会农·五谷的开垦耕地，会农·渔的开垦水泽，会畜牧·狩猎的开垦山林，会农·盐的开垦盐池，会百工·冶的开垦铜矿，会百工·奢侈品的开垦玉矿，会畜牧·驯马的开垦草场
- 和营建一样按投入的人力累积进度，视为官营，夏季农忙最慢
- 人力进度满后，新地块当回合到手。开垦期间，参与开垦的人不能从事其他工作

## 改良地块：水利

水利是一项工事，派士主事，带着会「百工·水利」的人去改良一块耕地。

- 和营建一样按投入的人力累积进度，视为官营，冬季做最快，夏季农忙最慢
- 完成后这块耕地升一级，每级产量提高 25%，最多 2 级
- 同一块地同一时间只能有一项水利工事

## 调整人口行业

调整人口行业由管理者直接下令，不需要派士人主事。正在做工事的人也可以调整，不用先撤下来。

### 学技能
- 管理者指定一群人中的多少人学哪一项新技能。新技能排在技能槽最后，要让他们以新技能为主业，再调整顺序
- 学一项新技能需要 1 回合。学习期间这些人照常干活，可以一边做工事一边学
- 不需要城中有人会这项技能
- 技能槽已满（4 项）时，要同时选一项旧技能丢弃
- 学成后，这些人从原来的人群中分出去，成为一群新的人；城中如果已有技能槽和文化图腾都相同的人群，就并入那群人
- 分出去时优先算未被管理的人；正在做工事的人分出去后，带着原来的工事继续做，只有新的技能槽做不了这项工事时（比如丢弃了它需要的技能）才撤下来

### 丢弃技能、调整顺序
- 当回合生效，不需要学习时间。正在学技能的人要等学成再调整
- 只能在这群人已有的技能中丢弃或调整顺序，至少保留一项
- 顺序就是优先顺序：未被管理时，他们按第一项技能自主民营
- 整群人一起调整时，直接改这群人的技能槽；只调整一部分人时，这些人分出去，规则和学技能相同

### 初始技能
没有人生下来什么都不会：
- 每群人至少有一项技能。开局没有指定技能的人群，只有初始技能（目前是农·五谷，可配置）
- 新生的人口继承所在人群的技能槽

## 赏赐民众

管理者可以把府库中的物资赏赐给民众，物资转入民间财富，当回合生效，不需要派士人。民间财富越多，全城的愉悦度越高（藏富于民）。

## 市与商贾

会「商业」的人经商，交易赚的钱币归民间财富。

- 没有市时，全城只能容纳 10 名商贾经商
- 每座市多容纳 40 名商贾。官营的市容纳官营经商的商贾，赚的钱币进府库；民营的市容纳民营经商的商贾，包括未被管理、自主经商的人
- 商贾越多，民间赚的钱币越多，全城越富，愉悦度越高，可征收的税也越多
- 市还用于和其他城市进行贸易，等多城市做出来之后再加

### 工事类型
调整人口行业、赏赐民众不是工事，由管理者直接下令，见上文。

- 生产：对应人口行业，如种五谷、制盐、狩猎、驯马、冶铸、铸造军备、铸礼器、琢玉、纺织
- 营建：在指定的地块上建造建筑，如城墙、宫殿、冶厂、市，通常持续多个回合。开工时要定下建成后官营还是民营，之后不能改
- 开垦：为城市开垦一块新地
- 水利：改良地块
- 军事训练
- 收税
- 祭祀

## 官营与民营

管理者可以通过士人调配人口去做官营或民营的工事，两者的区别在于产出归谁。

| | 官营 | 民营 |
|---|---|---|
| 产出归属 | 全部归府库 | 归民众，计入民间财富 |
| 府库如何获得 | 直接获得 | 只能通过收税获得一部分 |
| 生产效率 | 较低，为同类民营的 50% | 正常 |
| 对愉悦度的影响 | 降低，民众白干活，自己得不到任何东西 | 不降低；产出积累为民间财富，间接提升愉悦度 |

- 官营：急需某种物资时使用，比如备战时大量铸造战甲。代价是效率低、民心下降，长期大量官营会导致人口外流甚至造反
- 民营：平时养民。民众富裕之后愉悦度上升、人口增长，可征收的税也更多

### 官营建筑与民营建筑

建筑都是管理者派人建的，开工时就要定下建成后是官营还是民营，之后不能改。两者的区别只在产出归谁：

- 官营建筑：只能做官营的工事，产出全部进府库，产能为民营的 50%
- 民营建筑：只能做民营的工事，产出归民众，府库只能收税。未被管理的人口自主民营时，也只能用民营建筑
- 比如城中只有一座官营冶厂，就只能官营铸兵器；想让工匠自己冶铸，得另建一座民营冶厂
- 能劳作的建筑（冶厂、市）才分官营民营。城墙、宫殿这类建筑的效果对全城生效，不分
- 营建本身由府库出材料，参与营建的人视为服官营的劳役，不论建的是官营还是民营建筑
- 种地、捕鱼这类不靠建筑的劳作，仍由管理者在派士主事时选官营或民营

## 民间财富

民营的产出归全城民众共有，即民间财富（粮、盐、布、器物等）。城内各群人之间自动互通有无：比如农人产的粮、盐户产的盐，全城的人都能吃到。

- 民营的产出进入民间财富
- 人口的每回合消耗优先从民间财富中扣除，不足时由府库补足；仍然不足时，全城各群人按同一比例挨饿
- 收税从民间财富中征收，按被覆盖人群本回合的民营收入计算
- 管理者赏赐民众的财货也进入民间财富

城内的互通是自动的，不需要市。市用于和其他城市进行贸易。

藏富于民：全城民间财富按物品价值折算后，人均越多，所有人群的愉悦度越高。

## 收税

收税是一项工事，必须派士人主事。

- 主事士人能覆盖的人口有上限，没被覆盖到的人群交不上税
- 税率越高，被征税人群的愉悦度越低

所以士人的分配存在取舍：派去主持生产，还是派去收税。

## 士人管理上限

每名士人能管理的人口有上限：
- 基础值：50 人
- 根据士人的专精度、忠诚度、文化值上下浮动
- 出仕成为人物的士人有个人能力差异，能干的士人可管理更多人口

## 未被管理的人口

城市人口超过所有士人的管理能力时，多出来的人口无法被管理者调配。

- 他们按自己技能槽中的第一项技能自主民营，产出归自己
- 管理者无法指定他们做什么，也无法调动他们去营建、参军
- 没有被收税工事覆盖到的人群无法收税

城市人口多而士人少时，城市会变得「大而不治」。

### 从未被管理的人口中选拔士人
管理者可以从未被管理的人口中选择一部分人成为士人，再通过这些新士人去管理其余的人口。

- 被选中的人技能槽中已有「士」：可以直接任用为士人
- 被选中的人技能槽中没有「士」：先习得「士」技能，当回合即可任用为士人
- 被选中的人技能槽已满（4 个）：管理者需要先选择丢弃一项旧技能，再学习「士」

选拔士人有以下代价：
- 新士人能力较低：管理上限低于基础的 50 人，主事的经验积累之后才会逐渐提高
- 新士人和其他士人一样，由府库供养

## 回合与农时

一回合为一季，一年四个回合。不同季节适合做的事不同：

| 季节 | 农事 | 适合的工事 |
|---|---|---|
| 春 | 播种 | 春祭 |
| 夏 | 农忙 | 调用农人去做其他工事，代价最大 |
| 秋 | 收获 | 收税、秋祭 |
| 冬 | 农闲 | 营建、水利、军事训练 |

- 农忙时把农人调去做其他工事，会损失收成，并降低他们的愉悦度
- 技能槽里同时有农业和百工的人群，可以在农闲时做工，全年不闲着；只会一门手艺的人群专精度更高，但不产粮，需要别人供养

## 生产链

每个行业都有各自的原料、设施、产出和用途，彼此串成一张网。没有一座城什么都能产，城与城之间因此需要交易，也会因此产生争夺。

| 行业 | 需要 | 产出 | 用途 |
|---|---|---|---|
| 农·五谷 | 耕地地块、农时 | 粮 | 人口消耗、军粮、交易 |
| 农·盐 | 盐池或海滨地块 | 盐 | 人口消耗、交易 |
| 农·渔 | 水域地块 | 鱼 | 补充粮食 |
| 畜牧·狩猎 | 山林地块 | 肉、皮革、骨角 | 食物、甲、弓 |
| 畜牧·驯马 | 马匹、草场 | 战马 | 战车、交易、贡品 |
| 百工·冶 | 铜矿、冶厂（只需要铜，不需要锡） | 青铜 | 兵器、礼器的原料 |
| 百工·军备 | 青铜、皮革、木材 | 兵器、甲、弓矢、战车 | 装备军队 |
| 百工·礼器 | 大量青铜 | 鼎、簋 | 祭祀、彰显等级 |
| 百工·奢侈品 | 玉料 | 玉器 | 赠与、纳贡、提升愉悦度 |
| 百工·纺织 | 麻、桑蚕 | 布、帛 | 交易、赏赐、纳贡 |
| 百工·建筑 | 木、石、劳力 | 各类建筑 | 解锁设施 |
| 百工·水利 | 劳力 | 改良地块 | 提高农业产量 |
| 商业 | 市 | 钱币；城与城之间的物资流通 | 充实民间财富、换取本城不产的物资 |
| 军队 | 装备、粮 | 训练度 | 作战、守城 |

## 专精度与质量

专精度不仅影响产量，也影响质量。

- 专精度高的人群能产出精品。兵器、甲、鼎、簋、玉器、布都有精品：精兵、精甲、精鼎、精簋、精玉、细布
- 产出中精品的比例由技能槽中的技能数决定：1 项 30%，2 项 15%，3 项 5%，4 项没有精品
- 精品的价值是普通品的 3 倍，在纳贡、赠与、请封时价值远高于普通品
- 祭祀时，一件精品礼器折合两件普通礼器
- 部分高级物品只有专精度足够高的人群才能制作：铸鼎和琢玉要求技能槽中最多 2 项技能

## 礼器与列鼎制度

祭祀需要礼器，礼器越多、越精，祭祀的效果越好。但礼器的数量受爵位限制：

| 身份 | 用鼎上限 |
|---|---|
| 周天子 | 九鼎 |
| 公、侯 | 七鼎 |
| 伯、子 | 五鼎 |
| 男 | 三鼎 |
| 无爵 | 一鼎 |

拥有的鼎超过自己身份的上限，视为僭越，会扣风评。玩家因此需要权衡：多铸鼎能提升祭祀效果，却会违背礼法。

僭越只在发生时扣一次风评，之后一直保持超出也不会再扣：
- 超出得更多时，只扣多出的部分。比如男爵已有 5 鼎（超出 2 只，已扣过），再铸 1 只，只扣 1 只的风评
- 减到上限以内后又超出，算作新的僭越，再扣一次

## 规定任务

所有者可以给城市的管理者设定规定任务，比如每年上缴多少粮、多少布。所有者自己管理的城不需要规定任务；被攻占的城和原所有者没有上下级关系，也没有规定任务。

- 所有者随时可以设定、修改、取消规定任务。修改时，今年已经上缴的照样算数
- 管理者随时可以从府库上缴物资，一年内分几次交都行。上缴的物资进入所有者的私库（私库不属于任何城市，以后封授、赠与、纳贡、请封都从这里出）
- 没有规定任务时也可以上缴
- 每年冬季结算一次，看全年累计交够没有，然后清零重新累计。缺口和超额都按物品价值折算：
  - 完成任务：所有者对管理者的信任提升，有助于以后获得封授
  - 超额完成（每种物资都交够，且总价值达到规定的 1.2 倍）：信任大幅提升
  - 完不成任务：信任下降，差得越多降得越多，所有者可能收回管理权
- 换管理者后，今年已经上缴的不再算给新管理者
- 所有者收回管理权、自己管理后，规定任务随之取消；以后再交给别人管理时，重新设定

刚起步、还没有自己城市的玩家，可以先替别人管理城市，规定任务就是这一阶段的主要目标。

## 任命与收回管理权

- 所有者任命某人为管理者，对方接受后才生效；对方也可以拒绝
- 所有者随时可以收回管理权，自己管理，不需要管理者同意
- 一个人只能直接管理一座城：已经在管理一座城的人，不能接受第二座的任命，也不能把第二座城的管理权收回自己手里
- 城市被攻占时，所有者已经失去管理权，不能任命或收回
- 换管理者后，城中的士人、工事照旧，士人听命于新管理者

## 人口忠诚度

忠诚度是城中每群人对现任管理者个人的忠诚，和愉悦度分开计算。

- 换管理者时归零重来，旧管理者攒下的忠诚不能带走
- 税越低越忠诚：每回合按这群人实际承担的税（税率 × 被收税覆盖的比例）增减，税轻时上升，税重时下降
- 管理者赏赐民众时，所有人群的忠诚度按人均得到的财货价值上升
- 忠诚度低于门槛（300）时开始出现后果，越低越严重：
  - 官营罢工：派去官营生产、营建、开垦、水利的人只有一部分肯出工，忠诚度为 0 时只有一半。罢工的人回去按第一项技能自主民营，产出归自己
  - 民营不罢工，但收税收不上来：忠诚度为 0 时只能收上来一半
  - 民营产量下降：忠诚度为 0 时为平时的 80%
- 以后还会影响：所有者征调人口去别的城市、人口迁移、僭越时的负面效果、守城作战

## 随机事件

每回合有一定概率触发事件，每个事件给出 2～3 个选项。比如：

- 天灾：旱、涝、蝗灾，是否开仓赈济
- 流民来投：收留需要消耗粮食，驱逐会损失风评

很多事件的选项会和礼法、风评挂钩，把城市管理和礼法玩法联系在一起。

## 待定

- 具体数值：粮、盐等物品的产量和消耗，新士人的初始管理上限、能力提升的速度，每名士人每回合的开支，府库支付不起时的后果
