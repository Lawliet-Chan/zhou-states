# 人口

## 人口属性  
愉悦度：当人口所受税赋越低，人口愉悦度越高； 拥有者/管理者对人口使用越少，人口愉悦度越高。 人口愉悦度越高，人口繁殖越快，越能随机触发奢侈品种类和随机科技。 愉悦度越低，繁殖速度越低，产出越低，低于一定数值之后会离开城市。       

技能槽：同一群人可以同时具备多个行业，最多4个。  所身兼行业越多，则对单个行业的专精度越低。技能槽里技能越少，专精度越高。  

文化图腾：一种文化标志，每个城市最初都会有自己独特的文化。   
文化值：可通过祭祀提升，文化值高的人群所在的城市可以吸引更多的外来人口，且文化值高之后，如果被其他人强行攻陷此城，若攻击者的文化标志与此城人口不同，且文化值低于本城人口，则会有统治压力，统治压力越高，人口各方面产出越低，人民越容易造反， 一旦民众造反， 所有者和管理者将会丧失该城的所有权和管理权，并有概率被诛杀。    

忠诚度：对城市管理者的忠诚度，城市管理者可通过降低税收、给予民众财货等方式收获民众对自己的忠诚度。   
忠诚度高的人口可以被轻易迁移,并且做违背礼法的事情负面效果会更低，并且在守城作战中会有更高的战斗力   

每回合消耗：  每100个人口 一回合（一个月）消耗 0.67个粮食，0.33个盐（每季合计 2 粮、1 盐）

## 人口行业
### 士
士是一种特殊的人口，可以成为城市的管理者和所有者。技能槽中有「士」只表示具备士的能力，只有被管理者任用的人才是士人，所有士人都由府库供养。士平时和其他人口一样以人群的形式存在；当某个士被任命为管理者、接受封授或成为门客时，他会从人群中出仕，成为一个有名字的人物。  
玩家不可以直接操控人口去做某些事，需要通过士才可以，具体规则见 city-management.md。
比如给某个行业设置税收、训练、建造等等操作，必须要给该人群设置里放置一个士人才可以。 种类如下  
内政：祭祀；收税；迁移人口  
外交：出使他国
