# 玩家 

玩家只能最多只能直接手动管理操作一个城市，这意味着玩家如果有多个城市的话，他需要给这些城市单独设置士人来管理那些城市  
周天子由 NPC 扮演。  

## 玩家属性   
国籍：所属国家，玩家手里所有城市都隶属于该国家。  
名爵：公、侯、伯、子、男 五等爵位，必须由周天子册封才能得到礼法上的正式爵位，其他方式为僭越，违背礼法。 只有拥有公侯伯子男这五类爵位的其中一种，玩家才可以自己成立独立国家。 如果没有名爵则显示为无     
风评值   
礼法关系  


## 玩家资产

## 玩家行为
### 对人
封授：将所有权属于自己的城市封授给除了上司之外的其他人，城市的所有权会转让到被封授者身上，可选择封授时间，以及受封者要定期给自己的纳贡，时间越久，受封者对土地经营积极性越高。 除非受封者做了违反礼法 或者 风评值极低，否则不可以提前收回封地。   
任命/收回：可以把城市委任给下属或者门客来管理，但任命和封授不同，任命的城市可随时被收回，其城市的礼法关系不会发生转移。

立国：只能向周天子发起，成立国家，自己手里一切所有权归属于自己的城市，都将成为你成立的新国家的城市
