# 地图

## 方格
地图由各种六边形方格构成。 每个方格内包含地形、自然资源、人口数。单个方格能承载的自然资源和人口数都有上限。  

- 每格有 6 个相邻的格子，两格之间的距离就是从一格走到另一格要走几步
- 一格就是一块地：城市的地块就是地图上属于它的那些格子。不属于任何城市的格子是野地，城市可以把相邻的野地开垦进来（见 city-management.md 的「开垦」）
- 每座城有一个治所，城与城之间的距离从治所算
- 剧本里手画地图：一层画地形，一层画每格属于哪座城

## 地形  
每种地形有一个行军耗时：军队走进这种地形的一格要花多少行军力（各兵种每回合有多少行军力，等军队做出来再定）。都可以在配置里调，暂定：

| 地形 | 行军耗时 |
|---|---|
| 耕地、草场、盐池 | 1 |
| 山林、水泽、铜矿、玉矿 | 2 |
| 高山、大河 | 过不去 |

高山、大河是过不去的地形：军队不能走、不能住人、不能劳作、不能开垦，也不能属于城市，只能在剧本里画在野地上。示例剧本里画了两处高山、一段大河。
